# Sources — where every rule and card comes from, with dates

## Rules

- **Magic: The Gathering Comprehensive Rules, effective September 25, 2026.** Index page
  <https://magic.wizards.com/en/rules>. Plain text:
  `https://media.wizards.com/2026/downloads/MagicCompRules%2020260925.txt` — fetched 2026-10-03,
  HTTP 200, 977,752 bytes, kept in gitignored `scratch/rules/MagicCompRules.txt`. Every `// CR`
  comment in the engine cites this text. `docs/rules.md` is the index.

## Card data and deck lists

- **MTGJSON** build `5.3.0+20261002`, MIT licence for the dataset.
  - `https://mtgjson.com/api/v5/DeckList.json` — fetched 2026-10-03 (637,670 bytes).
  - `https://mtgjson.com/api/v5/decks/<fileName>.json` — one preconstructed deck with full card
    objects. Fetched files live in gitignored `scratch/data/`.
  - The card field the compiler reads is `text`, MTGJSON's Oracle text. Reminder text (in
    parentheses) is stripped before compiling and kept on the face.
- Only `data/cards.js` and `data/decks.js`, generated by `tools/build-cards.mjs`, are committed.
