# Sources — where every rule and card comes from, with dates

## Rules

- **Magic: The Gathering Comprehensive Rules, effective September 25, 2026.** Index page
  <https://magic.wizards.com/en/rules>. Plain text:
  `https://media.wizards.com/2026/downloads/MagicCompRules%2020260925.txt` — fetched 2026-10-03,
  HTTP 200, 977,752 bytes, kept in gitignored `scratch/rules/MagicCompRules.txt`. Every `// CR`
  comment in the engine cites this text. `docs/rules.md` is the index.

## Card data and deck lists

- **MTGJSON** build `5.3.0+20261002`, MIT licence for the dataset.
  - `https://mtgjson.com/api/v5/DeckList.json` — fetched 2026-10-03 (637,670 bytes).
  - `https://mtgjson.com/api/v5/decks/<fileName>.json` — one preconstructed deck with full card
    objects. Fetched files live in gitignored `scratch/data/`.
  - The card field the compiler reads is `text`, MTGJSON's Oracle text. Reminder text (in
    parentheses) is stripped before compiling and kept on the face.
- Only `data/cards.js` and `data/decks.js`, generated by `tools/build-cards.mjs`, are committed.

## Friends' decks (PLAN D21)

- **Kujo — "Zellix, of Halaster"** (Commander): the owner pasted Kujo's Moxfield list on 2026-10-31;
  it is kept as `data/lists/kujo-zellix.txt` (100 cards; the two-card sideboard left out, CR 903.5e).
  Oracle text from MTGJSON AtomicCards, re-fetched 2026-10-31
  (`https://mtgjson.com/api/v5/AtomicCards.json.gz`, 162,789,069 bytes unzipped). Before any change for
  this deck, the rebuild with it reproduced every earlier card and deck byte for byte; only
  `MF.LAND_NAMES` grew by the land names of sets printed since 2026-10-02. Every card now also carries
  its colour identity (`identity`, MTGJSON's `colorIdentity`; CR 903.4).
- **Scryfall API** (`https://api.scryfall.com/cards/named`, each card's `rulings_uri`), read 2026-10-31
  for the official rulings of Kujo's 102 cards, which the implementation follows. Kept in gitignored
  `scratch/kujo/rulings.json`; nothing from Scryfall is in the repository.

## Championship Commander decks (PLAN D22)

- **EDHTop16** (<https://edhtop16.com>): tournament pages and decklist pages, read 2026-10-31 with a browser
  user-agent (the site's data is embedded in each page; its GraphQL endpoint accepts only persisted queries).
  The tournament list came from its 2026 events page; the 16 largest open events' top 16 were scanned. Raw
  pages are kept in gitignored `scratch/web/cedh/`; `tools/fetch-cedh.mjs` writes the five chosen lists to
  `data/lists/cedh-*.txt`, each naming its event, standing, record, player and decklist URL:
  | Deck | Event | Date | Standing | Player |

  | Kraum & Tymna | Just Jam D-Grid | 2026-05-30 | 1st of 200 | Matt Hayes |
  | Thrasios & Vial Smasher | The Fish Bowl 7 | 2026-06-27 | 1st of 209 | Joe Holland |
  | Scion of the Ur-Dragon | cEDH UK Open — Benfest III | 2026-09-12 | 3rd of 156 | Janos Nado |
  | Najeela | Commandergeddon 10 | 2026-06-05 | 7th of 173 | Dan Cross |
  | Terra | Pittsburgh 2026 — t/cEDH $10k–$25,000 | 2026-07-11 | 8th of 195 | Nicholas Benson |
- Oracle text for their cards: the same MTGJSON AtomicCards file (2026-10-31). `data/cards.js` now also
  carries `MF.CARD_NAMES`, every card name in that file (34,907), for "choose a card name" (CR 201.3).
